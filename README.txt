تطبيق ويندوز (exe) لنظام محل الإكسسوارات
=========================================

الطريقة 1 — على جهاز ويندوز (الأسهل):
  1) ثبّت Node.js (نسخة LTS) من nodejs.org
  2) فك ضغط المجلد، واضغط مرتين على build.bat
  3) استنى لما يخلص (محتاج إنترنت). هيفتح لك مجلد dist وفيه:
       - Accessories Shop Setup 1.0.0.exe   (ملف تثبيت)
       - Accessories Shop 1.0.0.exe          (نسخة محمولة تشتغل بدون تثبيت)

الطريقة 2 — من غير ما تثبّت أي حاجة (GitHub):
  1) ارفع المجلد كله على مستودع GitHub جديد (فرع main)
  2) من تبويب Actions شغّل "Build Windows exe" وانتظر دقائق
  3) نزّل ملف windows-exe من نتيجة التشغيل (Artifacts)

لتجربة التطبيق قبل البناء: npm install ثم npm start

ملاحظات:
- ويندوز ممكن يظهر تحذير SmartScreen لأن البرنامج غير موقّع. اختار "More info" ثم "Run anyway".
- البيانات بتتحفظ على الجهاز (AppData). خد نسخة احتياطية من الإعدادات بشكل دوري.
- لنقل بياناتك من النسخة الأونلاين: "نسخة" هناك، ثم "استرجاع" في التطبيق.
- أيقونة مخصصة: ضع build/icon.ico (256x256) قبل البناء.

الجديد في النسخة 1.1 — الباركود والاسكنر
=========================================
- أي اسكنر (USB أو بلوتوث) يشتغل مباشرة بدون إعداد.
- شاشة «جديد»: امسح المنتج فيتضاف للفاتورة/العرض بصوت بيب (ولو مسحته تاني تزيد الكمية).
- أي شاشة تانية: المسح بيعرض اسم المنتج وسعره ومخزونه، وزر «أضف للفاتورة».
- كود غير مسجل: صوت تنبيه + زر لإضافته كمنتج جديد بنفس الكود.
- «المنتجات»: كل منتج ليه كود (يتولد تلقائي لو سبته فاضي، أو امسح باركود المنتج الأصلي).
- زر «توليد أكواد للناقص» يدّي أكواد للمنتجات القديمة، و«طباعة ملصقات» يطبع باركود (Code128) باسم وسعر المنتج.
- زر الكاميرا (بيشتغل فقط لو المتصفح/النظام بيدعم BarcodeDetector).
- الصوت يتقفل من الإعدادات.
